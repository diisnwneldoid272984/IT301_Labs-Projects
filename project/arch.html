Arch Linux

Arch is a rolling release distro. You only install what you need, so you learn how Linux works. It uses the pacman package manager.

Basic install steps

  1. Download the ISO and flash it to a USB drive.
  2. Boot from the USB and connect to the internet.
  3. Partition and format your drive.
  4. Run pacstrap to install the base system.
  5. Set up the bootloader, users, and a desktop.

Follow the full Arch Wiki installation guide.
